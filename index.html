Forecasting with Machine Learning

Aarhus University, autumn 2026. Code centered lecture slides are in .html format with embedded code to be executed directly in your browser.

This is a new course, centered around research papers which implement forecasting techniques in machine learning. Throughout, we will introduce and implement the models as implemented by the authors of the papers, keeping in mind best practices for conducting research and performing forecasting with machine learning.

Given that the course is new, we are particularly keen to receive feedback from students to improve the course content and delivery. Our main purpose is to facilitate an environment for you to delve deep into machine learning research, providing the foundation for you to build upon.

Overall Themes of the Course

Forecasting FoundationsStatistics, time-series analysis
Python ProgrammingMain libraries, machine learning, deep learning
Machine Learning LiteratureMacro, fixed income, and equity
Literature with Special DataFocus on high-frequency and energy data
