# Forecasting with Machine Learning

Course site for Forecasting with Machine Learning at Aarhus University, Department of Economics and Business Economics, by Kim Christensen, Bezirgen Veliyev and Natasia Villadsen. The repository contains the course pages and the lecture slides (`session_NN/`). The slides run Python in the browser, so no installation is needed until preparing for the exam.
