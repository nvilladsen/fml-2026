Lagging I

\[Y_t = f(X_{t-1}) + \varepsilon_t\]

To forecast \(Y_t\) we may only use what was known at \(t-1\), so the predictor is shifted back one period. Assume a random walk for simplicity – yet the concept holds for any predictor,

Generating data like this, with cumsum, because then it is a random walk path, \(y_t = y_{t-1} + \varepsilon_t = \sum_{s=0}^t\varepsilon_s\).

Standardization

\(Z\)-score standardization: Subtract the mean, divide by the standard deviation,

\[ z_t = \frac{x_t - \hat{\mu}}{\hat{\sigma}} \]

Yields \(z_t\) with zero mean and unit variance.

The Bias-Variance Trade-Off

The expected squared forecast error decomposes as

\[\mathrm{E}\!\left[(\hat{y} - y)^2\right] = \underbrace{\mathrm{Bias}^2}_{\text{underfitting}} + \underbrace{\mathrm{Variance}}_{\text{overfitting}} + \underbrace{\sigma^2}_{\text{irreducible}}\]

High bias

  • Model too simple
  • Misses systematic patterns
  • Train error \(\approx\) test error, both large

High variance

  • Model too complex/flexible
  • Model fits to noise rather than signal
  • Train error \(\ll\) test error

Regularized models, e.g., LASSO, trade off bias for variance, while ensembles such as random forests reduce variance

Penalized Regression Models I

  • Three primary penalized regression models; i) LASSO, ii) ridge, and iii) elastic net
  • Each adds a penalty term to the ordinary least squares (OLS) objective function of \(\ell_1\), \(\ell_2\), and both, respectively. The models are defined as,

\[\begin{aligned} \text{LASSO:}\quad \hat\beta_{\text{LASSO}} &= \underset{\beta}{\arg\min} \left\{ \sum_{t=1}^T(y_t - x_t^\top\beta)^2 + \lambda \sum_{j=1}^p |\beta_j| \right\}\\ \text{Ridge:}\quad \hat\beta_{\text{Ridge}} &= \underset{\beta}{\arg\min} \left\{ \sum_{t=1}^T(y_t - x_t^\top\beta)^2 + \lambda \sum_{j=1}^p \beta_j^2 \right\}\\ \text{Elastic net:}\quad \hat\beta_{\text{ENet}} &= \underset{\beta}{\arg\min} \left\{ \sum_{t=1}^T(y_t - x_t^\top\beta)^2 + \lambda\left[\rho\sum_{j=1}^p |\beta_j| + (1-\rho)\sum_{j=1}^p \beta_j^2\right] \right\} \end{aligned}\]

where \(\lambda \geq 0\) governs the penalty strength and \(\rho \in [0,1]\) the mix of \(\ell_1\) and \(\ell_2\).

Tip

In sklearn, the penalty strength is called alpha. For ridge, alpha \(=\lambda\). For LASSO, alpha \(=\lambda/(2T)\)

The elastic net nests the other two: \(\rho = 1\) gives the LASSO and \(\rho = 0\) gives ridge

Penalized Regression Models II: Selection and Shrinkage

  • The LASSO is a variable selection method, as, by virtue of the \(\ell_1\) penalty, coefficients can be set to exactly zero
    • Among strongly correlated predictors it tends to keep one and drop the others
  • Ridge shrinks all coefficients towards zero but sets none of them exactly to zero
  • The elastic net selects and shrinks, with \(\rho\) governing the mix
    • Correlated predictors tend to be kept or dropped together
  • The penalty strength \(\lambda\) and the mixing weight \(\rho\) are hyperparameters, tuned by time-series cross-validation

Penalized regression models trade off bias for variance relative to OLS

  • Three primary penalized regression models; i) LASSO, ii) ridge, and iii) elastic net

  • Each adds a penalty term to the ordinary least squares (OLS) objective function of \(\ell_1\), \(\ell_2\), and both, respectively

  • The Least Absolute Shrinkage and Selection Operator (LASSO) penalizes according to the absolute value of the coefficients, the \(\ell_1\) penalty

  • This makes the LASSO a variable selection method, as it can set coefficients exactly to zero

  • Ridge penalizes according to the squared value of the coefficients, the \(\ell_2\) penalty

  • Elastic net combines the two penalties, \(\ell_1\) and \(\ell_2\), in a convex combination

  • Under regularity conditions, OLS is unbiased, but it can have high variance, especially in high-dimensional settings (many predictors)

  • Penalized regression handles high dimensionality well, but are fundamentally biased estimators

  • We trade off bias for variance

Decision Trees

  • A tree forecasts by splitting the training data into nodes with yes/no questions about one predictor at a time, e.g., “is lagged inflation \(\leq 6.88\)?”
  • Nodes that are not split further are the leaves
  • The forecast of leaf \(k\) is the mean of the training targets that end up in it,

\[\hat y_k = \frac{1}{n_k}\sum_{t \in \mathcal{L}_k} y_t\]

  • where \(\mathcal{L}_k\) is the set of training observations in leaf \(k\), and \(n_k\) is their number

  • A new observation is forecast by its associated leaf, assigned via the decision path

Decision Trees: Growing a Tree

  • A split asks “is \(x_{t,j} \leq s\)?”, with \(x_{t,j}\) predictor \(j\) in observation \(t\) and \(s\) the cut point
  • Each side of the node is forecast by its own mean target, \(\bar y_{\text{left}}\) and \(\bar y_{\text{right}}\), giving the squared error

\[\text{SSE}(j,s) = \sum_{t:\; x_{t,j} \leq s}\left(y_t - \bar y_{\text{left}}\right)^2 + \sum_{t:\; x_{t,j} > s}\left(y_t - \bar y_{\text{right}}\right)^2\]

  • The pair \((j, s)\) with the smallest SSE is chosen. We repeat in each new node until a stopping rule is met

Deep trees fit the training data closely but have high variance – a single tree is unstable

The left/right means are only used to score each candidate split. Only the leaves produce actual forecasts.

Random Forests

Reduce the variance of trees by averaging many trees grown on different bootstrap samples,

1

Bootstrap

Draw \(B\) samples with replacement from the training data

2

Grow

Fit a deep tree on each sample, using only \(m < p\) randomly chosen predictors at each split, decorrelating the trees

3

Average

The forecast is the average over the \(B\) trees

\[\hat{f}_{\text{RF}}(x) = \frac{1}{B}\sum_{b=1}^{B}\hat{f}_b(x)\]

Forecasts are averages of training targets, so a forest cannot predict outside the range of the targets

Expanding and Rolling Windows

So far, the model was estimated once and used for the whole test sample.

A real-time forecaster would generally re-estimate as new data arrives,

1

Estimate

Fit the model on rows before \(t\) only

2

Forecast

Predict row \(t\)

3

Move on

Go to row \(t+1\) and repeat

Expanding: fit on all rows before \(t\). Rolling: fit on the last \(W\) rows before \(t\)

Expanding and Rolling Windows: Code

  • We fit OLS with expanding and rolling window estimation
  • X[:t] is rows \(0, \ldots, t-1\) (the end is excluded)
  • Row \(t\) of X holds information from \(t-1\), so no future data enters the fit
