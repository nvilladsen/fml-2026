Before the exam

Setup

The exam is without internet. Therefor, Python and the relevant packages must be installed on your own laptop prior to the exam.

The exam is on your own PC, with no internet. Finish this page well before the exam and repeat the check in step 5 with the network switched off.

  1. Install Python

    Download Python from python.org. Use version [Python version] so that your results match the materials.

  2. Install VS Code

    Download Visual Studio Code and add the Python and Jupyter extensions from the extensions panel.

  3. Create a virtual environment

    Open a terminal in your course folder and run the commands for your system. The environment keeps the course packages separate from everything else on your laptop.

    Windows (PowerShell)

    py -m venv .venv
.venv\Scripts\Activate.ps1

    macOS and Linux

    python3 -m venv .venv
source .venv/bin/activate

  4. Install the packages

    With the environment active, run:

    pip install numpy pandas scikit-learn statsmodels matplotlib jupyter

    Placeholder: confirm the package list and add exact versions, for example in a requirements.txt.

  5. Check that it works

    Run the line below, once with internet and once with the network switched off. It should print ready.

    python -c "import numpy, pandas, sklearn, statsmodels, matplotlib; print('ready')"
