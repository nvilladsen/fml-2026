Case: Forecasting the Equity Premium with Machine Learning

Forecasting with Machine Learning, Case 2

Objective

In this case you are to forecast the monthly US stock market excess return, following the time-series part (sections 1.2 and 1.3) of the Rapach and Zhou (2020), Time-series and Cross-sectional Stock Return Forecasting: New Machine Learning Methods paper, and investigate whether machine learning methods, including a random forest and a neural network (not considered in the paper), improve on the simple prevailing mean forecast.

The case combines the elements of the course so far:

  • The forecasting pipeline introduced in Lecture 3: lagged predictors, chronological samples, and modeling, here with OLS and penalized regression, and random forests, and standardization without leakage
  • The neural network of Lecture 4 and Case 1: training loop, early stopping, regularization, and ensembles over seeds
  • Expanding-window evaluation as in Lecture 6 (Dong et al., 2022): prevailing mean benchmark, combination forecasts, the C-ENet, the Clark-West test, and a mean-variance investor

Note that some of the expanding window implementations you are to run are somewhat heavy, and so might take a few seconds to minutes to run. Hence, please be patient with your notebook.

Much of the above was implemented in Lecture 6 with 100 anomaly returns as predictors. In this case, there are only 12 predictors, which keeps the code short and the run time manageable. You may reuse your own functions from the exercises and from Case 1.

The case is not to be handed in, nor will you receive feedback. You are encouraged to work in groups, and to discuss the problems with your fellow students. You will be provided with suggested solutions to the problems, but we recommend you attempt to solve the problems on your own first. Data

You will use the dataset contained in the file rapach_zhou_case.csv, built from Amit Goyal’s updated version of the Welch and Goyal (2008) data and from FRED (producer prices (PPIACO)/PPI inflation and industrial production (INDPRO)), following section 1.3.1 of the paper. The file can be read in directly from the course GitHub using the code pd.read_csv("https://raw.githubusercontent.com/nvilladsen/fml-2026/main/assets/data/rapach_zhou_case.csv"). The dataset spans 1,104 months, between January 1927 to December 2018.

The target variable, y, is the excess return of the S&P 500 in month \(t\), in percent (\(r_t\)), while date represents the month associated with the return. The 12 predictors at time \(t\) are observed at the end of month \(t-1\), so they are already lagged relative to y. This means that lagging of the predictors is not necessary. PPI inflation and industrial production growth are lagged by one additional month, accounting for publication lags (data is not necessarily available at the time of the forecast). The dataset contains the following predictors:

The sample must be split in alignment with the paper: an initial in-sample period of 1927 – 1946 (240 months), a holdout period of 1947 – 1956 (120 months), and an evaluation period of 1957 – 2018 (744 months). The forecasting scheme is expanding window.

import numpy as np

def r2_oos(actual, forecast, benchmark):
    # Out-of-sample R2 in percent, relative to the benchmark forecast (eq. [1.16])
    return 100 * (1 - np.sum((actual - forecast) ** 2) / np.sum((actual - benchmark) ** 2))


def clark_west(actual, forecast, benchmark):
    # Clark-West (2007) MSFE-adjusted statistic (one-sided t-statistic, as in Lecture 6)
    # Significant if above 1.28 (10%), 1.645 (5%) and 2.33 (1%)
    f = (actual - benchmark) ** 2 - (actual - forecast) ** 2 + (benchmark - forecast) ** 2
    return f.mean() / (f.std(ddof=1) / np.sqrt(len(f)))


def coordinate_pass(variables, a, g, G, lam_l1, lam_l2, lower, active):
    # one cycle of coordinate descent over `variables`; updates a (coefficients) and g (gradient) in place
    # returns the largest squared coefficient change and the change in R-squared
    largest_change, gain = 0.0, 0.0
    for k in variables:
        u = g[k] + a[k]
        shrunk = abs(u) - lam_l1                      # soft-thresholding by the l1 part
        new = max(lower, np.sign(u) * shrunk / (1 + lam_l2)) if shrunk > 0 else 0.0
        d = new - a[k]
        if d != 0:
            if k not in active:
                active.append(k)                      # glmnet visits active variables in order of entry
            gain += d * (2 * g[k] - d)
            a[k] = new
            g -= G[:, k] * d
            largest_change = max(largest_change, d * d)
    return largest_change, gain


def enet_aicc(X, y_, lower=-np.inf, alpha=0.5, n_lambda=200, tol=1e-7, patience=100):
    # elastic net path as in glmnet; returns (intercept, coefficients) at the AICc-minimizing lambda
    n, p = X.shape
    mean, sd = X.mean(0), X.std(0)
    sd = np.where(sd > 1e-12, sd, np.inf)
    Z = (X - mean) / sd                               # standardized predictors
    yc = y_ - y_.mean()
    sd_y = yc.std()
    g = Z.T @ (yc / sd_y) / n                         # gradient, updated along the way
    G = Z.T @ Z / n
    a = np.zeros(p)                                   # coefficients
    active, rsq, rsq_before, passes_done = [], 0.0, 0.0, False

    lam_max = np.abs(g).max() / alpha                 # smallest lambda that sets all coefficients to zero
    step_ratio = (1e-4 if n >= p else 1e-2) ** (1 / (n_lambda - 1))
    best_aicc, best_a, best_m = n * np.log(yc @ yc / n), a.copy(), 0     # the null model

    for m in range(1, n_lambda):
        lam = lam_max * step_ratio ** m
        lam_l1, lam_l2 = lam * alpha, lam * (1 - alpha)
        full_pass = not passes_done
        while True:
            if full_pass:                              # cycle over all variables
                change, gain = coordinate_pass(range(p), a, g, G, lam_l1, lam_l2, lower, active)
                rsq += gain
                if change < tol:
                    break
                passes_done = True
            while True:                                # cycle over the active variables until converged
                change, gain = coordinate_pass(list(active), a, g, G, lam_l1, lam_l2, lower, active)
                rsq += gain
                if change < tol:
                    break
            full_pass = True
        residual = yc / sd_y - Z @ a
        df = np.count_nonzero(a)
        aicc = n * np.log(residual @ residual * sd_y ** 2 / n) + 2 * df * n / (n - df - 1) if n - df - 1 > 0 else np.inf
        if aicc < best_aicc:
            best_aicc, best_a, best_m = aicc, a.copy(), m
        glmnet_stops = m >= 4 and (rsq - rsq_before < 1e-5 * rsq or rsq > 0.999)
        if glmnet_stops or m - best_m >= patience:    # patience: stop when AICc has not improved for 100 lambdas
            break
        rsq_before = rsq
    coef = best_a * sd_y / sd
    return y_.mean() - mean @ coef, coef

Problem 8: Statistical evaluation

  1. Report the \(R^2_{\text{OOS}}\) (in percent) and the Clark-West statistic of the OLS, combination, elastic net, C-ENet, random forest and network (ensemble) forecasts in one table, and compare with Panel B of Table 1.1.

The cumulative difference in squared forecast errors (CDSFE) is defined as

\[ \text{CDSFE}_t = \sum_{s=t_2}^{t} \left[(r_s - \bar{r}_s)^2 - (r_s - \hat{r}_s)^2\right] \]

where \(\bar{r}_s\) is the prevailing mean forecast and \(\hat{r}_s\) is the forecast of interest. The CDSFE measures the cumulative improvement in forecast accuracy of a given model relative to the prevailing mean. A positive CDSFE in month \(t\) indicates that the model has outperformed the prevailing mean in total up to month \(t\), while a negative CDSFE indicates the opposite.

  1. Plot the cumulative difference in squared forecast errors between the prevailing mean and each of the six forecasts (cf. Figure 1.7). How do you read such a plot? Which forecasts outperform the prevailing mean consistently over time?
  2. Do the random forest and the network improve on the linear methods? Link your answer to the conditions under which trees and neural networks performed well in Gu et al. (2020), and to the bias-variance discussion of section 1.2.2 of the paper.

Appendix: Optional extension – Does predictability last?

This extension is optional, since the case is already quite extensive, and since this subject is somewhat distant from what the lectures have touched upon.

McLean and Pontiff (2016), Does Academic Research Destroy Stock Return Predictability?, study 97 cross-sectional return predictors (anomalies) from the academic literature. For each predictor they compare the long-short return in three periods: the sample period of the original study, the period after the sample ends but before the study is published, and the period after publication. They find that returns are about 26% lower out-of-sample and about 58% lower post-publication than in-sample. The decline out-of-sample but before publication is attributed to statistical bias (data mining: researchers report the predictors that happened to work in their sample). The additional decline after publication is attributed to investors learning about the predictor from the publication and trading on it, which removes part of the mispricing (the public learns about the market being in “disequilibrium” and moves, via supply/demand, the price closer to the fundamental value, the equilibrium price).

The question posed, whether academic research “destroys” predictability, is relevant to time-series predictability as well. The simple combination forecast was proposed by Rapach, Strauss and Zhou (2010), a paper with an empirical application using a sample ending in 2005. If publication destroys predictability, we would expect the combination forecast to perform worse after 2005, and after 2010 in particular. Of course, given we are considering only one such paper, any evidence found, whether supportive or contradictory to the hypothesis, will necessarily be anecdotal.

To test the hypothesis of McLean and Pontiff (2016), the in-sample, out-of-sample, and post-publication periods must be compared.

  1. Split the evaluation period (using the same data as we have used all along) into three periods:
    i) 1957:01 – 2005:12, the period covered by Rapach et al. (2010) (in-sample)
    ii) 2006:01 – 2009:12, after the Rapach et al. (2010) sample, before publication (out-of-sample)
    iii) 2010:01 – 2018:12 (post-publication)

    Report the \(R^2_{\text{OOS}}\) of each of the six forecasts of Problem 8.a in each period.

    Hint: the function r2_oos can be applied to a subsample with a boolean array (True in the months of the subsample), e.g., r2_oos(actual[mask], fc[mask], pm[mask]).

  2. Does your evidence suggest that publication destroyed the predictability of the market excess returns, as McLean and Pontiff (2016) find for cross-sectional anomalies? Why should the comparison be interpreted with caution?
